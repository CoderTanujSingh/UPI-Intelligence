# UPI-Intelligence
Built a fintech analytics dashboard using Power BI to analyse UPI transaction data. The project includes customer behaviour analysis, fraud detection, bank and merchant insights, transaction monitoring, and advanced KPI reporting with interactive dashboards and DAX calculations.

**Tools & Technologies Used**

-Power BI <br>
-DAX <br>
-Power Query <br>
-Excel/CSV <br>
-Sharepoint <br>
-Data Modelling <br>
-Fintech Analytics <br>
-Dashboard Design <br>
