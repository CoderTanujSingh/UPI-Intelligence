# UPI-Intelligence
Built a fintech analytics dashboard using Power BI to analyse UPI transaction data. The project includes customer behaviour analysis, fraud detection, bank and merchant insights, transaction monitoring, and advanced KPI reporting with interactive dashboards and DAX calculations.

**Tools & Technologies Used**

-Power BI

-DAX

-Power Query

-Excel/CSV

-Data Modelling

-Fintech Analytics

-Dashboard Design


**Bonus Senior-Level Add-ons**

-Add AI Features

-Transaction anomaly detection

-Predict failed transactions

-Customer segmentation using clustering

-Integration Ideas

-SQL Database

-Python Fraud Model

-Real-Time API Simulation
